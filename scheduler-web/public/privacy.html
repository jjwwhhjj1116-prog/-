1. 수집하는 개인정보 항목 및 수집 방법

회사는 원활한 업무 협업 및 구글 드라이브(Google Drive) 연동 서비스를 제공하기 위해 아래와 같은 정보를 수집 및 처리합니다.

  • 사내 계정 정보: 사용자 이름, 사내 이메일, 소속 부서, 직급, 시스템 고유 ID
  • Google 계정 정보 (OAuth 2.0 연동 시): Google 사용자 이메일 주소(concost_dt@gmail.com 등), 인증 토큰(Access Token 및 Refresh Token)
  • Google Drive API 권한 (drive.file): 서비스 내에서 사용자가 직접 생성하거나 백업 요청한 프로젝트 일정 데이터 및 산출물 파일에 한하여 읽기/쓰기 권한을 사용합니다.

2. 개인정보 및 Google 사용자 데이터의 이용 목적

  • 프로젝트별 마감/구조/토목 공종 일정표 및 담당자 배정 관리
  • Google Drive 내 지정된 업무 폴더에 프로젝트 일정 및 성과물 안전한 클라우드 백업 및 동기화
  • 사용자 본인 식별, 권한 부여(관리자/팀원 구분) 및 무단 접근 방지

3. Google API 데이터 제한적 사용 정책(Limited Use Requirements) 준수

본 서비스는 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy) 및 제한적 사용 요구사항(Limited Use requirements)을 철저히 준수합니다.

  • Google 드라이브에서 수집된 토큰 및 데이터는 사용자가 명시적으로 승인한 백업 및 저장 목적으로만 사용되며, 광고 또는 타 마케팅 목적으로 사용되지 않습니다.
  • Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않습니다.
  • Google API를 통해 얻은 데이터를 인간이 검토하거나 인공지능/머신러닝 모델 학습에 사용하지 않습니다.
